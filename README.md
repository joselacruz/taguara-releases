# Taguara POS — versiones

Instaladores de Taguara POS para Windows. La app instalada busca aquí las actualizaciones.

- **Releases:** instaladores (`Taguara-POS-*-setup.exe`) y `latest.yml`, publicados automáticamente.
- **`version-policy.json`:** versión mínima obligatoria (`minVersion`) y su motivo (`reason`).
